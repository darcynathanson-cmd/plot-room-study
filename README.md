# Plot room study

A photo of Plot turned into points, blocks and lines using estimated depth.

Open `index.html` in a browser with WebGL. No Blender or installation needed. Drag to turn the room, or focus it with Tab and use the arrow keys. Try the six effects, replay the reveal, or save a PNG or GIF loop.

PNG exports are 1920 x 1352 pixels. GIF loops are 640 x 466 pixels and four seconds long.

One photo is included. Depth is approximate; turning can expose gaps and stretched edges.

[Prepare other photos](PHOTO-SETS.md) or [try a small code edit](HOW-TO-EDIT.txt). The photo importer is under "Source & how it works".
